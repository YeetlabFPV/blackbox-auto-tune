# Blackbox Auto-Tune

A macOS beta for Betaflight Blackbox analysis and tuning suggestions.

[Download the DMG](https://github.com/YeetlabFPV/blackbox-auto-tune/releases) · [Flight guide](outputs/Anleitung.md) · [Feedback](https://github.com/YeetlabFPV/blackbox-auto-tune/issues)

Apple Silicon, macOS 14 or later. Open the DMG and drag the app to Applications. This beta is ad-hoc signed and macOS may ask you to approve it in Privacy & Security.
